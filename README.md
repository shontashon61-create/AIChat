# AIChat v2 - iOS-приложение для чата с ИИ

SwiftUI, OpenAI-совместимый API, стриминг, модели, размышления ИИ, фото/видео, камера, голос.

## Что нового во v2
- Markdown: код-блоки с кнопкой Копировать, жирный/курсив, списки.
- Поиск по чатам и внутри чата, закрепление, переименование, счётчик сообщений, превью последнего ответа.
- Редактирование своего сообщения: текст возвращается в поле ввода, ответ перегенерируется.
- Сжатие картинок до 1024px / JPEG 0.75 перед отправкой — chats.json больше не раздувается, отправка быстрее.
- API: таймауты 30/120 сек, понятные ошибки HTTP с телом ответа, обрезка контекста (по умолчанию последние 20 сообщений), max_tokens, поддержка /models в виде строк и объектов, чистка Base URL от хвостов /models и /chat/completions.
- Видео: честная пометка в тексте, что модель видео не видит, вместо молчаливой потери вложения.
- Настройки: пресеты системного промта, проверка подключения, экспорт чатов файлом через Share Sheet, авто-озвучка, лимит контекста и токенов.
- История: пустые чаты не плодятся — кнопка Новый чат переиспользует пустой.
- Голос: очистка markdown перед озвучкой, ошибки доступа к микрофону показываются, а не молчат.
- Скролл: следование за стримингом по мере появления текста, а не только по числу сообщений.

## Функции v1
- Настройки: API Base URL (по умолчанию https://positionapi.top/v1), API Key, системный промт, температура, уровень размышления, тёмная тема.
- Модели: загрузка из GET /models, выбор в шапке и в настройках.
- Чат: стриминг POST /chat/completions, reasoning_content в блоке Ход мыслей ИИ, история, перегенерация, копирование, удаление.
- Медиа: галерея (фото/видео до 15 МБ, макс 5 за раз), камера, vision-картинки как image_url base64.
- Голос: диктовка на русском, озвучка ответов ru-RU.

## Важно про IPA на Windows
IPA собирается только Xcode на macOS. На Windows xcodebuild нет, поэтому проект + скрипт, а IPA — одним из способов ниже.

## Способ 1: на Mac
```bash
chmod +x build_ipa.sh
./build_ipa.sh
```
Получится AIChat-unsigned.ipa рядом с проектом.

## Способ 2: GitHub Actions (без Mac)
1. Залей папку в репозиторий GitHub.
2. Actions -> Build unsigned IPA -> Run workflow.
3. Скачай артефакт AIChat-unsigned-ipa.

## Установка на iPhone
- AltStore / SideStore / Sideloadly: установи AIChat-unsigned.ipa со своим Apple ID.
- TrollStore (если поддерживается iOS): без переподписи и без срока 7 дней.

## Первый запуск
1. Шестерёнка.
2. Проверь Base URL, вставь API Key.
3. Нажми Проверить подключение и обновить модели, выбери модель.
4. Выбери пресет промта или вставь свой, пиши.
